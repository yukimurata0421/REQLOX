# Project description draft

REQLOX turns incident and system descriptions into inspectable reliability
conditions, then separates proposals from execution authority and observed
results. Its interfaces support archived incident/System IR review, finite
caller preparation, isolated fault experiments, candidate checks, confirmation
and result auditing.

Recorded copied-module checks reproduced api and worker failures and confirmed
their candidates under fault, normal and ownership conditions. Adoption stayed
inside isolated copies. Temppath's existing README checks found no counterexample;
four atomic bindings remain HELD, with no repair performed. Missing historical
raw observations remain unknown.

The owner application is hosted on a dedicated GCP VM through a Cloud Run
gateway. A separate static review surface is implemented for anonymous reading,
with no private Workspace access or new computation. Live availability is
verified separately from the source checks.
The copied Target scope is closed at 15/15 campaigns and 62/120 seconds.
Independent generalization, Source benefit, calibration and effort savings
remain unproven.

the evidence. Do not substitute a loaded credential or hosting receipt for an
actual AI execution record.
